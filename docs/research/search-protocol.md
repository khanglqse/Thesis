# Literature search protocol

Search date: 2026-09-07. Sources are discovered through web search and followed to publisher, project, proceedings, DOI or official documentation pages. Technical claims use primary sources. Inclusion requires direct relevance to traffic-signal control evaluation, mixed-motorcycle simulation/calibration, or Da Nang observations. Exclusion reasons include inaccessible metadata, unsupported marketing claims, unrelated detection results, and duplicate preprint/publication records.

Query families:

- `traffic signal control reinforcement learning pressure coordination`
- `traffic signal control robustness generalization benchmark RESCO`
- `motorcycle mixed traffic microsimulation calibration Vietnam`
- `Da Nang turning movement counts traffic survey`
- the same families with a 2023–2026 date filter, while retaining foundational work

For every included source, the matrix records access level and the exact design decision it supports. Abstract-only evidence is marked and will not be used to assert equation-, table-, or protocol-level details.
